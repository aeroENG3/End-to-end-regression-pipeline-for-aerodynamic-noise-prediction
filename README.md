# NASA Airfoil Noise Prediction

This project predicts the **scaled sound pressure level (SSPL)** generated by an airfoil using a linear regression model. It uses the NASA Airfoil Self-Noise dataset to relate airfoil geometry and operating conditions to aerodynamic noise.

## Deliverable

- `NASA_Airfoil_Noise_Prediction_Explained.ipynb` — the annotated notebook, including project explanations, code comments, exploratory analysis, model training, evaluation, model saving, and a Gradio prediction interface.

## Problem statement

Aerodynamic noise is affected by the airfoil configuration and flow conditions. The goal is to estimate SSPL from five measurable input variables. This notebook uses linear regression as an interpretable baseline model; more complex models may improve accuracy if non-linear patterns are important.

## Dataset

The notebook downloads the Kaggle dataset `fedesoriano/airfoil-selfnoise-dataset` through `kagglehub`. It contains 1,503 observations and these columns:

| Column | Meaning | Unit | Role |
| --- | --- | --- | --- |
| `f` | Frequency | Hz | Feature |
| `alpha` | Angle of attack | Degrees | Feature |
| `c` | Chord length | m | Feature |
| `U_infinity` | Free-stream velocity | m/s | Feature |
| `delta` | Suction-side displacement thickness | m | Feature |
| `SSPL` | Scaled sound pressure level | dB | Target |

## Notebook workflow

1. Download and load the CSV data.
2. Inspect distributions, trends, descriptive statistics, and correlations.
3. Create `X` (five predictor columns) and `y` (`SSPL`).
4. Split the observations into 70% training data and 30% test data with a fixed random seed.
5. Train a scikit-learn `LinearRegression` model.
6. Evaluate train and test predictions using Mean Squared Error (MSE) and R-squared (R²).
7. Save the fitted model as `AirNoise.pkl`.
8. Launch a Gradio interface to enter feature values and receive an SSPL prediction.

## Results in the supplied notebook

The recorded run reports approximately:

| Split | MSE | R² |
| --- | ---: | ---: |
| Train | 23.38 | 0.514 |
| Test | 22.38 | 0.515 |

The similar training and test scores suggest there is no clear overfitting, but an R² of about 0.51 also shows that a simple linear model leaves meaningful variation unexplained. Feature engineering or non-linear models can be evaluated as future improvements.

```bash
pip install kagglehub numpy pandas matplotlib seaborn scikit-learn joblib gradio
```

The optional Streamlit/ngrok cells additionally require `streamlit` and `pyngrok`. They contain a placeholder ngrok token and should only be used after you supply your own token; the Gradio section is the self-contained demonstration interface.

## How to run

1. Open `NASA_Airfoil_Noise_Prediction_Explained.ipynb` in Jupyter Notebook, Google Colab, or Kaggle.
2. Run the cells from top to bottom. The first cell downloads the dataset and defines its folder path.
3. Run the model-saving cell before the Gradio cell so `AirNoise.pkl` exists.
4. Use values within the ranges represented by the training data whenever possible. Predictions outside those ranges are extrapolations and may be less reliable.
