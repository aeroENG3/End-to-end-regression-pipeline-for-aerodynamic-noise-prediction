## ✈️ Overview & Physics Context

Aerodynamic noise generated by airfoils is a major operational constraint in aerospace engineering, wind turbine design, and UAV/drone propulsion. Airfoil self-noise primarily originates from the interaction between the turbulent boundary layer and the trailing edge.

This repository implements a regression model trained on experimental wind-tunnel data collected by NASA. The model maps 5 key aerodynamic and structural features directly to acoustic output decibels ($\text{dB}$).

### **System Dataflow**
```text
┌─────────────────────────────────────────┐
│           Input Features                │
│  • Frequency (f)                        │
│  • Angle of Attack (α)                  │ ───► ┌───────────────────────────┐      ┌─────────────────┐
│  • Chord Length (c)                     │      │ Linear Regression Model   │ ───► │  Predicted SSPL │
│  • Free-stream Velocity (U_∞)           │      │ (scikit-learn pipeline)   │      │      (in dB)    │
│  • Displacement Thickness (δ)           │      └───────────────────────────┘      └─────────────────┘
└─────────────────────────────────────────┘

```

## 📊 Dataset Architecture

The dataset originates from NASA's anechoic wind tunnel tests on 2D NACA 0012 airfoil sections. It contains **1,503 experimental observations**.

| Variable | Name | Units | Description | Role |
| --- | --- | --- | --- | --- |
| $f$ | `f` | Hz | Frequency of acoustic emission | **Feature** |
| $\alpha$ | `alpha` | degrees | Geometric angle of attack | **Feature** |
| $c$ | `c` | meters | Airfoil chord length | **Feature** |
| $U_\infty$ | `U_infinity` | m/s | Free-stream airflow velocity | **Feature** |
| $\delta^*$ | `delta` | meters | Suction-side boundary layer displacement thickness | **Feature** |
| **SSPL** | `SSPL` | dB | **Scaled Sound Pressure Level** | **Target** |

## ⚙️ Machine Learning Workflow

1. **Data Ingestion**: Programmatically loaded via `kagglehub` (`fedesoriano/airfoil-selfnoise-dataset`).
2. **Exploratory Data Analysis (EDA)**: Correlation analysis, distribution skewness checks, and acoustic spectrum visualization.
3. **Data Partitioning**: Stratified 70/30 Train-Test split ($N_{\text{train}} = 1052$, $N_{\text{test}} = 451$).
4. **Model Training**: Trained an interpretable `LinearRegression` baseline.
5. **Serialization**: Exported model artifacts to `AirNoise.pkl` via `joblib`.
6. **Deployment Interface**: Self-contained web app built with `Gradio`.

## 📈 Baseline Model Performance

| Metric | Training Set (70%) | Testing Set (30%) | Metric Interpretation |
| --- | --- | --- | --- |
| **Mean Squared Error (MSE)** | `23.38` | `22.38` | Low variance between splits confirms no overfitting |
| **Root Mean Squared Error (RMSE)** | `4.84 dB` | `4.73 dB` | Average prediction deviation from ground truth |
| **Coefficient of Determination ($R^2$)** | `0.514` | `0.515` | Baseline linear variance explained |

> **Key Takeaway**: The close parity between train and test performance demonstrates solid model generalization. However, non-linear relationships (e.g., logarithmic frequency response) suggest ensemble tree models (XGBoost/Random Forest) will yield higher accuracy in future iterations.

## 💻 Interactive Web Interface

You can launch the prediction web application locally directly through Gradio:

```python
import joblib
import numpy as np
import gradio as gr

# Load saved model artifact
model = joblib.load("AirNoise.pkl")

def predict_sound_level(f, alpha, c, U_inf, delta):
    inputs = np.array([[f, alpha, c, U_inf, delta]])
    sspl_pred = model.predict(inputs)[0]
    return f"{round(float(sspl_pred), 2)} dB"

demo = gr.Interface(
    fn=predict_sound_level,
    inputs=[
        gr.Number(label="Frequency (Hz)", value=1000),
        gr.Number(label="Angle of Attack (deg)", value=0.0),
        gr.Number(label="Chord Length (m)", value=0.3048),
        gr.Number(label="Free-stream Velocity (m/s)", value=71.3),
        gr.Number(label="Displacement Thickness (m)", value=0.0026),
    ],
    outputs=gr.Text(label="Predicted Sound Pressure Level (SSPL)"),
    title="✈️ NASA Airfoil Self-Noise Predictor",
    description="Enter flight conditions and geometric parameters to estimate noise emission."
)

demo.launch()

```
