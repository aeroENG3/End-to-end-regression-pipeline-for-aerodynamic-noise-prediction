# ✈️ NASA Airfoil Self-Noise: Advanced ML Prediction Pipeline

## 📖 Overview

Predicting the acoustic footprint of aerodynamic bodies is critical for virtual prototyping, acoustic quieting, and optimizing lift-to-noise ratios in UAVs, wind turbines, and commercial aircraft.

This repository contains an end-to-end, production-ready Machine Learning pipeline designed to predict the **Scaled Sound Pressure Level (SSPL, in dB)** generated by a NACA 0012 airfoil section. The project bridges the gap between aerodynamic physics and data science by utilizing custom physics-informed feature engineering, rigorous cross-validation, and MLOps tracking.

## 📊 The Problem & Dataset

**Goal:** Supervised regression to predict airfoil self-noise based on five measured wind-tunnel quantities.
**Source:** [Kaggle: fedesoriano/airfoil-selfnoise-dataset](https://www.kaggle.com/datasets/fedesoriano/airfoil-selfnoise-dataset) (Originally from the NASA Langley Research Center anechoic wind tunnel).

| Variable | Symbol | Unit | Description |
| --- | --- | --- | --- |
| **Frequency** | $f$ | Hz | Pitch of the noise component being measured (200 to 20,000 Hz) |
| **Angle of Attack** | $\alpha$ | degrees | Angle between the incoming flow and the chord line |
| **Chord Length** | $c$ | m | Width of the airfoil section |
| **Free-stream Velocity** | $U_\infty$ | m/s | Wind-tunnel flow speed |
| **Displacement Thickness** | $\delta$ | m | Boundary-layer parameter on the upper (suction) surface |
| **Target (SSPL)** | $SSPL$ | dB | Intensity of the self-noise generated by the airfoil |

## 🧠 Physics-Informed Feature Engineering

Rather than relying purely on raw inputs, the pipeline utilizes a custom scikit-learn transformer (`AerodynamicFeatureEngineer`) to extract physics-based relationships, enhancing the predictive power of the models:

* **Strouhal Number ($St$):** The primary dimensionless metric in aeroacoustics, describing oscillating flow mechanisms.
* **Effective Reynolds Number ($Re$):** Captures the boundary layer turbulence characteristics.
* **Mach Number ($Ma$):** Accounts for compressibility effects.
* **Stall Indicator:** A binary flag for conditions where $\alpha \ge 10^\circ$, representing flow separation and structural stall limits.
* **Log-Frequency:** Normalizes the exponentially spaced acoustic frequency spectrum.

## ⚙️ Architecture & MLOps Pipeline

1. **Data Preprocessing:** Strict separation of training and validation sets before applying an `OutlierHandler` (IQR clipping) and `RobustScaler` to prevent data leakage.
2. **Model Portfolio:** Benchmarks multiple algorithms including Ridge, Lasso, ElasticNet, Random Forest, Gradient Boosting, SVR, and a Voting Ensemble.
3. **Experiment Tracking:** Integrated **MLflow** automatically logs hyperparameters, model artifacts (Pickle), and metrics (RMSE, MAE, R², CV standard deviation, and Overfitting Gaps).
4. **Hyperparameter Tuning:** Utilizes `RandomizedSearchCV` for efficient state space exploration across tree-based and regularized linear models.
5. **Deployment Artifacts:** Automatically generates a `model_card.json`, `requirements.json`, and serialized `.pkl` files for the preprocessor and the tuned model.

## 🚀 Usage

### 1. Training the Pipeline & Tracking Experiments

Run the main Python script to execute the data splitting, model training, hyperparameter optimization, and MLflow logging.


